MARIA PAZ BRAVO STUDIO — STATIC WEBSITE

Files:
- index.html
- styles.css
- script.js
- assets/ (logo + project images)

This site has no paid platform dependency and no build process.
To test it, open index.html in a browser.

Important:
- The hero image intentionally contains NO text.
- The logo uses object-fit: contain and is never cropped.
- The contact form opens the visitor's email app addressed to ceo@mariapazbravo.com.
